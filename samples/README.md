# Sample wallpapers

Real files copied unmodified from [SerStars/Nugget-Wallpapers](https://github.com/SerStars/Nugget-Wallpapers)
(licence: GPL-3.0, see `../LICENSE`). They are used by the unit tests and by the test procedure in the main README.

| File | Author (from the upstream manifest) | Why it is useful |
|---|---|---|
| `Night_City.tendies` | squair.dev | 3 layer packages, springs/keyframes, Locked/Unlock/Sleep states, light + dark gradients |
| `TintedCubes.tendies` | @dootskyre | `CATransformLayer` 3D cubes inside a `CAReplicatorLayer`, light/dark states |
| `RainbowSprinkles.tendies` | @dootskyre | `CAEmitterLayer` particles, mixed-size documents (3176² background + 428×926 foreground) |
| `MOJOCARROT.tendies` | @dularkian on GitHub | Apple "ParameterizedCA" style: gyro parallax groups (absolute ranges), animated shape paths |
| `LavaLamp.batter` | @dularkian on GitHub | `.batter` template: `set` options patched through `nuggetId`, image slot, blur |
| `wallpapers-template.json` | upstream | A real catalog manifest for the catalog-parser test |

More samples: `scripts/fetch_samples.sh` downloads any file of the upstream repo.
Artwork belongs to the respective authors; check their terms before redistributing.
